# Lab 01 Student Task

## Task 1 — Run the Calculator

Run `calculator.py` and demonstrate all four operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division

Also demonstrate the following:

- Invalid menu selection
- Invalid numerical input
- Division by zero

---

## Task 2 — Understand the Code

Identify the following in `calculator.py`:

1. Functions
2. Conditional statements
3. Loop
4. Exception handling
5. User input
6. Program entry point

Write your answers in `answers.md`.

---

## Task 3 — Modify the Calculator

Add two new operations:

5. Modulus
6. Power

Update the menu accordingly.

For example:

10 % 3 = 1

2 ^ 3 = 8

---

## Task 4 — Add Automated Tests

Add tests for:

- Modulus
- Power
- Negative numbers
- Decimal numbers

All tests should pass.
