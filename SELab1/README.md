# Lab 01 — Python Calculator

## Course

Software Engineering

## Lab Title

Introduction to Python, Git and GitHub

## Duration

2 Hours

## Difficulty

Beginner

---

# Learning Objectives

After completing this lab, students will be able to:

1. Create and execute a Python program.
2. Understand basic Python functions.
3. Use conditional statements.
4. Handle user input.
5. Handle exceptions.
6. Use Git for version control.
7. Create commits and branches.
8. Push code to GitHub.
9. Write basic automated tests.
10. Execute tests using pytest.

---

# Software Requirements

Students need:

- Git
- GitHub account
- Python 3.x
- VS Code or another IDE

Alternatively, students can use Google Colab.
